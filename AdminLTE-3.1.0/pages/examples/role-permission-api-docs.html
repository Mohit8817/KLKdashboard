KLK DLE — Role & Permission (RBAC) API Documentation

Complete technical documentation for all Role-Based Access Control (RBAC), Permission Catalog, User Role Assignment, Attendance, User Master, and External Integration Credential APIs in the KLK DLE project.

3. Role & Permission Management APIs

Base URL: /api/portal/access | Authentication: Bearer Token (JWT)

GET /api/portal/access/permissions

Lists all assignable permissions in the catalog for role creation and editing.

// Response: 200 OK
{
  "success": true,
  "data": [
    {
      "id": 3,
      "key": "portal.bihar.ssl_amc.read",
      "label": "Bihar SSL AMC — view",
      "module": "bihar_amc",
      "description": "View Bihar SSL AMC data in this app."
    },
    {
      "id": 5,
      "key": "portal.bihar.ssl_amc.add",
      "label": "Bihar SSL AMC — add",
      "module": "bihar_amc",
      "description": "Add / upload Bihar SSL AMC data in this app."
    }
  ],
  "meta": { "total": 10 }
}
GET /api/portal/access/roles Admin Only

Lists all custom roles created in the caller's company.

// Response: 200 OK
{
  "success": true,
  "data": [
    {
      "id": "1",
      "company_id": "KLK-COMPANY-01",
      "name": "Bihar Field Team",
      "description": "Field inspections and uploads",
      "user_count": 4,
      "permission_keys": [
        "portal.bihar.light_amc.read",
        "portal.bihar.light_amc.add"
      ],
      "created_at": "2026-09-20T10:00:00.000Z",
      "updated_at": "2026-09-20T10:00:00.000Z"
    }
  ]
}
POST /api/portal/access/roles Admin Only

Creates a new custom role with designated permissions.

// Request Body
{
  "name": "UP Field Supervisor",
  "description": "Field inspections in UP",
  "permission_keys": [
    "portal.up.ssl_amc.read",
    "portal.up.ssl_amc.add"
  ]
}

// Response: 201 Created
{
  "success": true,
  "message": "Role created.",
  "data": {
    "id": "2",
    "name": "UP Field Supervisor",
    "permission_keys": [
      "portal.up.ssl_amc.read",
      "portal.up.ssl_amc.add",
      "portal.up.ssl_amc.dashboard"
    ]
  }
}
PUT /api/portal/access/roles/:id Admin Only

Updates an existing role's name, description, and permissions.

// Request Body
{
  "name": "UP Senior Field Supervisor",
  "description": "Updated description",
  "permission_keys": [
    "portal.up.ssl_amc.read",
    "portal.up.ssl_amc.add",
    "portal.up.light_amc.read"
  ]
}
DELETE /api/portal/access/roles/:id Admin Only

Deletes a custom role by ID and unassigns it from members.

// Response: 200 OK
{
  "success": true,
  "message": "Role deleted."
}
GET /api/portal/access/roles/:id/users Admin Only

Returns the list of user IDs belonging to a role.

// Response: 200 OK
{
  "success": true,
  "data": {
    "role_id": "2",
    "user_ids": ["101", "105", "108"]
  }
}
PUT /api/portal/access/roles/:id/users Admin Only

Replaces all members assigned to a role with a new array of user IDs.

// Request Body
{
  "user_ids": ["101", "105", "109"]
}

// Response: 200 OK
{
  "success": true,
  "message": "Role assigned to 3 user(s).",
  "data": {
    "user_ids": ["101", "105", "109"],
    "member_count": 3
  }
}
GET /api/portal/access/users/:userId/roles Admin Only

Returns all roles assigned to a user.

// Response: 200 OK
{
  "success": true,
  "data": {
    "user_id": "101",
    "roles": [
      {
        "role_id": "1",
        "role_name": "Bihar Field Team",
        "permission_keys": [
          "portal.bihar.light_amc.read",
          "portal.bihar.light_amc.add"
        ]
      }
    ],
    "role_ids": ["1"]
  }
}
PUT /api/portal/access/users/:userId/roles Admin Only

Updates the roles assigned to a specific user.

// Request Body
{
  "role_ids": ["1", "2"]
}

// Response: 200 OK
{
  "success": true,
  "message": "User roles updated.",
  "data": [
    {
      "role_id": "1",
      "role_name": "Bihar Field Team",
      "permission_keys": ["portal.bihar.light_amc.read", "portal.bihar.light_amc.add"]
    }
  ]
}
GET /api/portal/access/me

Returns current authenticated user's permissions and RBAC management capability. Called upon user login.

// Response: 200 OK
{
  "success": true,
  "data": {
    "user_id": "101",
    "company_id": "KLK-COMPANY-01",
    "permission_keys": [
      "portal.bihar.ssl_amc.read",
      "portal.bihar.ssl_amc.add"
    ],
    "can_manage_rbac": false
  }
}
GET /api/portal/access/users Admin Only

Lists company users for member assignment dropdowns. Accepts optional query ?search=.

4. External Portal API Credentials APIs

Base URL: /api/portal/access/api-credentials | Authentication: Bearer Token (users.role = 1)

Method Endpoint Path Description
GET /api-credentials List external API credentials for the company
POST /api-credentials Generate new API Key & Secret (Scopes: read, approve, all)
PUT /api-credentials/:id Update label, scopes, or active status
POST /api-credentials/:id/rotate-secret Rotate/change secret password
DELETE /api-credentials/:id Revoke and delete API credential
GET /api/portal/access/integration-catalog Full API catalog and curl examples for admin
GET /api/portal/integration/me External caller self-discovery endpoint (Auth via X-Portal-Api-Key & X-Portal-Api-Secret)

6. Frontend API Client Routes Mapping (SDK Reference)

The structured client routes object used across frontend services and Axios calls:

export const API_ENDPOINTS = {
  // Attendance Module
  attendance: {
    today: '/api/attendance/today',
    month: '/api/attendance/month',
    punchIn: '/api/attendance/punch-in',
    punchOut: '/api/attendance/punch-out',
  },

  // User Master Module (Admin Only)
  userMaster: {
    users: '/api/user-master/users',
    user: (id) => `/api/user-master/users/${id}`,
  },

  // Portal RBAC & Access Management Module
  portal: {
    permissions: '/api/portal/access/permissions',
    roles: '/api/portal/access/roles',
    role: (id) => `/api/portal/access/roles/${id}`,
    roleMembers: (id) => `/api/portal/access/roles/${id}/users`,
    users: '/api/portal/access/users',
    userRoles: (userId) => `/api/portal/access/users/${userId}/roles`,
    me: '/api/portal/access/me',
    bootstrap: '/api/portal/access/bootstrap',
    apiCredentials: '/api/portal/access/api-credentials',
    apiCredential: (id) => `/api/portal/access/api-credentials/${id}`,
    apiCredentialRotateSecret: (id) =>
      `/api/portal/access/api-credentials/${id}/rotate-secret`,
    integrationCatalog: '/api/portal/access/integration-catalog',
  },

  // External Portal Integration Profile
  portalIntegration: {
    me: '/api/portal/integration/me',
  },

  // Bihar ULA Surveys Module
  biharUla: {
    list: '/api/bihar/ula/list',
    checkUnique: '/api/bihar/ula/check-unique',
    store: '/api/bihar/ula/store',
    view: (id) => `/api/bihar/ula/${id}`,
    downloadImagesZip: (id) => `/api/bihar/ula/${id}/download-images`,
    secondVisit: (id) => `/api/bihar/ula/${id}/second-visit`,
  },
};
